## ЧТО ЭТО

TOP-5 Analysis Bot — это AI-система для автоматического анализа арбитражных кампаний. 

**Цель:** Находить не очевидные возможности для масштабирования (SCALE), которые не видны в стандартных отчетах.

**Принцип:** Игнорировать очевидное, фокусироваться на скрытом потенциале через анализ волатильности и глубокий токен-майнинг.

## КАК РАБОТАЕТ БОТ

### 1. ОТБОР КАМПАНИЙ

Бот НЕ выбирает просто лучшие кампании по ROI. Он ищет:

- **Высокую волатильность** (изменчивость результатов) — это сигнал возможности
- **Положительную динамику** (рост за последние 3 дня)
- **Неочевидные паттерны** в токенах (комбинации, которые дают аномально высокую конверсию)
- **Резервы для оптимизации** (например, высокий ROI при малом объеме трафика)

### 2. КРИТЕРИИ ПОПАДАНИЯ В TOP-5

✅ **ДА:**
- Волатильность 5-30% (изменчивые результаты)
- Рост метрик за 3 дня минимум на 15%
- Минимум 60 кликов (статистическая значимость)
- Найдены аномалии в токенах (редкие комбинации с высоким CR)

❌ **НЕТ:**
- Очевидные лидеры с максимальным ROI (уже работают на пике)
- Стабильные кампании (variance < 5%)
- Показанные менее 48 часов назад
- Менее 60 кликов за период

### 3. SCORING СИСТЕМА

Каждой кампании присваивается SCORE на основе взвешенных факторов:

| Фактор | Вес | Обоснование |
|--------|-----|-------------|
| Волатильность | ×3.0 | Высокая изменчивость = возможность |
| Рост за 3 дня | ×2.5 | Тренд важнее абсолютного значения |
| Аномалии токенов | ×2.0 | Скрытые сегменты = золото |
| ROI текущий | ×1.0 | Базовая метрика |
| Объем данных | ×0.5 | Статистическая значимость |

**Формула:**
```
SCORE = (Volatility × 3.0) + (Growth_3d × 2.5) + (Token_Anomaly × 2.0) + (ROI × 1.0) + (LOG10(Clicks) × 0.5)
```

## 26 СТОЛБЦОВ

### СТРУКТУРА ДАННЫХ

Каждая запись содержит 26 столбцов, анализируемых на **3 уровнях глубины**:

#### Level 1 (Поверхностный) — для ВСЕХ кампаний
Базовые агрегированные метрики:
- Total Clicks = SUM(Click)
- Total Cost = SUM(Cost)
- Total Revenue = SUM(Conversion × Payout)
- ROI = ((Revenue - Cost) / Cost) × 100
- CR = (Conversions / Clicks) × 100
- Impact = Revenue - Cost

#### Level 2 (Средний) — для топ-30% (score > 60)
Сегментация по категориям:
- По Traffic Source (какой источник даёт лучший ROI)
- По Device Type (Mobile vs Desktop vs Tablet)
- По Country (топ-5 гео по конверсиям)
- По OS (Android vs iOS)
- По Lander ID (какие лендинги конвертят лучше)

#### Level 3 (Глубокий) — для топ-10 финалистов
Многомерный анализ токенов (FP-Growth):
- Комбинации токенов (Token1=X AND Token3=Y → ROI > 200%)
- Аномалии (редкие значения < 5% кликов, но 30%+ конверсий)
- Кросс-сегментация (Token + Device + OS Version = микросегмент)
- Временные паттерны (токены, работающие в определённые часы)

## АЛГОРИТМ ИНСАЙТОВ

### ЧТО ТАКОЕ НЕОЧЕВИДНЫЕ ИНСАЙТЫ

Система избегает банальных выводов и ищет скрытые возможности.

#### ❌ ПЛОХИЕ ИНСАЙТЫ (очевидные):
- "Кампания X имеет ROI 250%, увеличьте бюджет" — видно в любом отчёте
- "Mobile трафик дешевле Desktop" — общеизвестный факт
- "iOS конвертит лучше Android" — базовая сегментация

#### ✅ ХОРОШИЕ ИНСАЙТЫ (неочевидные):
- "Креатив #3873 (Token2) на Android 13+ даёт CR 18% против общего CR 4%, но получает только 2% трафика. Потенциал: $500/день"
- "Лендинг Mobile (Token3=1665_1_WD_La) показывает decline 25% за 3 дня на iOS, но Desktop версия растёт на 40%. Причина: баг на Safari 17.2+"
- "Browser Chrome Mobile + Language=Spanish конвертит в 3× лучше English, хотя объём Spanish всего 7%. Нужен таргетинг"

### МЕХАНИЗМ ПОИСКА

#### Шаг 1: Базовый анализ (для всех)
1. Тренд-анализ: сравнение последних 3 дней с предыдущими 7 днями
2. Детекция аномалий: выявление дней с резкими скачками (> 50% deviation)

#### Шаг 2: Сегментный анализ (Level 2)
Для каждого категориального поля:
- **SPI** (Segment Performance Index) = (Segment ROI / Campaign Average ROI) × 100
- **Volume Share** = % кликов в сегменте
- **Opportunity Score** = SPI × (100 - Volume Share) — недоиспользуемый потенциал

**Пример:**
```
Device Type = Mobile
ROI = 180%, Average ROI = 120%, Volume = 15%
SPI = (180 / 120) × 100 = 150
Opportunity Score = 150 × (100 - 15) = 12,750
→ Mobile недополучает трафик!
```

#### Шаг 3: Токен-майнинг (Level 3, FP-Growth)
1. Создание транзакций (каждый клик = транзакция с токенами)
2. Фильтрация (убрать токены frequency > 50% или < 1%)
3. FP-Growth с min_support=2%, min_confidence=60%
4. Ранжирование паттернов по Lift × ROI

## ВОЛАТИЛЬНОСТЬ

### ЗАЧЕМ НУЖНА

Показывает степень изменчивости результатов. Высокая волатильность означает:
- Кампания в фазе тестирования
- Внешние факторы влияют на результат
- Есть возможность для оптимизации
- Найден новый прибыльный сегмент, не масштабированный

### ФОРМУЛА РАСЧЁТА

Комбинация 3 метрик:

**1. Standard Deviation (σ)**
```
σ = √(Σ(xi - μ)² / N)
где xi = значение метрики в день i, μ = среднее, N = дней
```

**2. Coefficient of Variation (CV)**
```
CV = (σ / μ) × 100%
Нормализованная волатильность для сравнения
```

**3. Range Ratio (RR)**
```
RR = (Max - Min) / Median
Размах колебаний относительно медианы
```

**Итоговая формула:**
```
Volatility_Score = (CV_ROI × 0.4) + (CV_CR × 0.3) + (RR_Impact × 0.3)
```

### ИНТЕРПРЕТАЦИЯ

| Score | Категория | Действие |
|-------|-----------|----------|
| < 5% | Низкая (стабильная) | Исключить из TOP-5 |
| 5-15% | Средняя | Кандидат для TOP-5 |
| 15-30% | Высокая | Приоритет для TOP-5 |
| > 30% | Экстремальная | Требует проверки |

## СИСТЕМА ОБУЧЕНИЯ

### ФИЛОСОФИЯ

Бот использует **Reinforcement Learning**: каждое действие пользователя записывается и влияет на будущие рекомендации.

### КНОПКИ ДЕЙСТВИЙ

#### 🟢 SCALE (Масштабировать)
- **Когда:** Высокий ROI + есть резерв для роста
- **Эффект:** +20% к score для похожих кампаний
- **Обучение:** Система запоминает успешные паттерны (токены, сегменты, волатильность)

#### 🟡 HOLD (Подождать)
- **Когда:** Интересна, но нужно больше данных
- **Эффект:** Нейтральный вес, повышается min порог кликов
- **Обучение:** Система учитывает необходимость стат. значимости

#### 🔴 OPTIMIZE (Оптимизировать)
- **Когда:** Есть проблемы (низкий CR, высокая стоимость)
- **Эффект:** -10% к score если проблемы не исправлены
- **Обучение:** Больше внимания worst performers секции

### HIDE FOR N DAYS

Временно исключить кампанию из TOP-5:
- **3 дня** (по умолчанию) — недостаточно данных
- **7 дней** — в процессе оптимизации
- **14 дней** — тест новых креативов
- **30 дней** — полная пауза

**Реализация:**
```sql
INSERT INTO hidden_campaigns (campaign_id, hidden_until)
VALUES (?, NOW() + INTERVAL ? DAY)
```

### CALL AI COUNCIL

Расширенный AI-анализ конкретной кампании:
1. Нажатие кнопки → API запрос к LLM (GPT-4/Claude)
2. Передача полного датасета кампании
3. Получение структурированного JSON с рекомендациями
4. Отображение в модальном окне с reasoning + конкретные действия

## ВРЕМЕННЫЕ ИНТЕРВАЛЫ

### БАЗОВОЕ ПРАВИЛО

**Кампания НЕ может появиться в TOP-5 снова, если прошло < 48 часов с момента последнего показа.**

Это предотвращает "зацикливание" и обеспечивает разнообразие инсайтов.

### ИСКЛЮЧЕНИЯ

1. **Резкое изменение метрик:** ROI изменился на ±50% за 24 часа
2. **Критический объём:** Spend > $500 за 24ч при негативном тренде (срочное предупреждение)
3. **Пользовательский запрос:** Кнопка "Refresh" игнорирует правило 48ч

### ЛОГИКА HIDE FOR N DAYS

| Период | Причина | Исключение |
|--------|---------|------------|
| 3 дня | Недостаточно данных | Spend > $1000 за 72ч |
| 7 дней | В процессе оптимизации | ROI упал > 100% |
| 14 дней | Тест новых креативов | Нет |
| 30 дней | Полная пауза | Нет |
